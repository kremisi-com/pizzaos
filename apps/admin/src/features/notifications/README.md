# Notifiche Admin

Contratto UI condiviso per richiedere toast accessibili. Le feature importano `useAdminToast` da questo entry point; la composizione fornisce il provider e possiede presentazione, durata e coda delle notifiche. Nessuna dipendenza dalla composizione o persistenza.

Verifica con la suite Admin `admin-toast.test.tsx` e `pnpm architecture:check`.
