# Requisiti osservabili

1. Gli ingressi HTTP e worker riusano le stesse regole, persistenza e autenticazione del servizio esistente. Il runtime comune non apre una porta né avvia riconciliazioni periodiche. L'ingresso locale standalone continua a servire Fastify e riconciliare ogni 5 secondi.
2. Tutte le variabili richieste dal runtime attuale restano obbligatorie: DATABASE_URL, AUTH_SECRET, PIZZAOS_PROXY_SECRET, PIZZAOS_ALLOWED_ORIGINS, PIZZAOS_SUPERADMIN_EMAILS, AUTH_GOOGLE_ID, AUTH_GOOGLE_SECRET, SMTP_URL, AUTH_EMAIL_FROM, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET. Assenze e valori vuoti falliscono prima di inizializzare risorse; il messaggio nomina il campo senza includere valori. Nessun fallback simulato.
3. AUTH_SECRET e PIZZAOS_PROXY_SECRET hanno almeno 32 caratteri e sono distinti. Le origini sono URL canonici senza credenziali, path, query, fragment o wildcard; HTTPS obbligatorio salvo loopback HTTP quando NODE_ENV non è production. Email superadmin normalizzate a minuscolo, almeno una valida; no email demo riservata.
4. PIZZAOS_ENVIRONMENT facoltativa ammette solo test/production, default production. In test sono ammesse solo chiavi Stripe sk_test_; una chiave live non deve avviare il processo test. Il tempo riserva pagamento positivo è configurabile (default 10 minuti).
5. Il worker parte con una riconciliazione immediata e poi ogni 5000 ms per default. Nessuna sovrapposizione se tick è ancora pendente. Errori sono notificati a onError e il tick successivo resta possibile; nessun dettaglio segreto è loggato dalla libreria.
6. start ripetuto non duplica timer o tick. stop annulla il timer e attende il tick in corso; dopo stop non partono nuovi tick. stop ripetuto è innocuo; start dopo stop non riattiva il worker. Intervalli non interi/positivi falliscono prima di avviare lavoro.
7. L'artefatto distribuito include soltanto bundle, dipendenze e configurazione necessari. Non contiene .env, dati di test, sessioni browser o segreti. API e worker sono due ingressi distinti; il worker mantiene il ritmo anche senza richieste HTTP.
