# Interfacce pubbliche UI

Stub firme `public.stub.ts`. Le feature ricevono PromotionsApi pubblico; non importano implementazioni servizio o composition interne.

`apps/client/src/features/promotions/index.ts` esporta `PromotionSelectionPanel` con props `{api:PromotionsApi;storeId:string;selection?:PromotionSelection;disabled?:boolean;refreshVersion?:number;onChange:(selection:PromotionSelection)=>void;onTermsChange?:()=>void}` e `PromotionSummary` con props `{quote:IndividualQuote}`. Il pannello mostra wallet e selezione, non calcola prezzi. Etichette: «Saldo punti», «Punti disponibili», «Codici coupon» (codici separati da virgola, sequenza percentuali preservata), «Applica coupon», «Usa premio fedeltà». Il summary mostra «Prodotti prima degli sconti», «Sconti coupon», «Premio fedeltà», «Prodotti netti», «Consegna» e totale forniti dal server.

`apps/admin/src/features/promotions/index.ts` esporta `PromotionAdminPanel` con props `{api:PromotionsApi;storeId:string;products:IndividualProduct[];refreshVersion?:number}`. Etichette programma: «Programma attivo», «Punti per euro», «Punti per premio», «Valore premio (€)», «Salva programma». Coupon: «Nuovo coupon», «Codice coupon», «Tipo coupon» (`percent`/`fixed`), «Valore coupon», «Coupon attivo», «Valido dal», «Valido fino al», «Spesa minima (€)», «Limite totale», «Limite per cliente», «Salva coupon»; elenco pulsanti «Modifica <codice>». Prodotti ammessi checkbox con nome del prodotto; nessuna selezione = tutti. Date input datetime-local convertite ISO; valori economici euro convertiti cent, percentuale convertita basis point nel solo adapter UI per costruire la configurazione (server rivalida tutto).

Adapter HTTP `createPromotionsApi():PromotionsApi` in ciascuna app sotto composition/api/promotions-api.ts. Tutte le chiamate same-origin/no-store, credenziali cookie. Errori strutturati come IndividualApiError. IndividualOrderingScreen e PersistentGroupScreen ricevono prop opzionale `promotionsApi?:PromotionsApi` per mantenere compatibili consumer esistenti; le shell live la forniscono sempre. Il draft individuale conserva soltanto selezione `benefits` con validazione forma; la richiesta checkout originale recuperata conserva la selezione identica.

La composizione admin monta un pannello «Coupon e fedeltà» per la sede attiva, recuperando prodotti mediante IndividualApi e passando solo port/props pubblici. Coupon e programma non appartengono al form catalogo né alle vecchie feature demo loyalty.
