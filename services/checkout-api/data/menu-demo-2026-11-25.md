## Procedura ripetibile

Da `services/checkout-api`, esportare la connessione di test in `DATABASE_URL` e `PIZZAOS_ENVIRONMENT=test`. Non inserire credenziali nel repository o negli argomenti dei comandi.

```powershell
pnpm exec tsx src/import-isolated-demo-menu.ts data/menu-demo-2026-11-25.json
pnpm exec tsx src/import-isolated-demo-menu.ts data/menu-demo-2026-11-25.json --apply
```

Il primo comando esegue solo letture. Il secondo ricalcola il piano sotto lock tramite il repository canonico. Aggiunge la sola bozza e il suo Magazzino, senza cambiare pubblicato, altre bozze, sedi, ordini, riserve o pagamenti. Controlla nome e ID della sede, database, isolamento delle ricette, validatori canonici e limite di 20 bozze. Dati già cambiati, collisioni degli ID di Magazzino o dell'identità della bozza bloccano tutto atomicamente. La corrispondenza del Magazzino usa gli ID, senza imporre suffissi nei nomi visibili. Rieseguire lo stesso manifest senza modifiche intermedie non cambia ID, scorte, snapshot o revisione.
